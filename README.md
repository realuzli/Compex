Clínica Estética - Sistema de Agendamento

Objetivo
Sistema web para organizar clientes, horários disponíveis e agendamentos de uma clínica de estética fictícia, eliminando conflitos de horário e facilitando a visualização dos próximos atendimentos.

Tecnologias utilizadas
- Python 3
- Flask (framework web)
- SQLite (banco de dados)
- HTML/CSS (frontend)
- Jinja2 (templates)

 Instruções para execução
1. Clone o repositório:
2. Acesse a pasta do projeto:
3. Instale as dependências:
 pip install flask
4. Execute o sistema:
   python app.py
5. Acesse no navegador:
http://localhost:5000
Funcionalidades implementadas
- Cadastro de clientes
- Cadastro de horários disponíveis
- Agendamento de horário para um cliente
- Cancelamento de agendamento
- Validação para impedir que dois clientes sejam agendados no mesmo horário
- Tela de listagem dos próximos agendamentos
